# AVILESTILO® — Sitio web

## Qué incluye
- Landing page responsive para celular, tablet y PC.
- Catálogo de 6 referencias cargadas con las imágenes reales recibidas.
- Filtros por Jeans, Joggers, Baggi y Bermudas.
- Selector de tono y talla.
- Botón de compra que abre WhatsApp al 300 395 8114 con producto, tono y talla.
- Chatbot flotante básico en JavaScript.
- Menú móvil.
- SEO básico.
- Sin servidor ni base de datos: es una web estática, ideal para Vercel.

## Archivos
- index.html
- styles.css
- script.js
- assets/

## Publicar en Vercel
1. Entra a https://vercel.com/
2. Inicia sesión.
3. Pulsa "Add New..." → "Project".
4. Puedes subir/conectar este proyecto según la opción que te muestre Vercel.
5. Selecciona la carpeta del proyecto.
6. Pulsa Deploy.
7. Vercel te entregará una dirección pública.
